
# Ticket Studio

A customizable Discord ticket bot with a visual Components V2 panel builder.

## Features

- Discord Components V2 panels
- Dropdown ticket categories
- Custom modal forms
- Multiple panel configurations
- Private ticket channels
- Claim and close buttons
- HTML transcripts
- SQLite storage
- Interactive web dashboard

## Website

Hosted using GitHub Pages from the /docs directory.

## Bot

Python 3.10+ and discord.py 2.6+.

Install dependencies:

    pip install -r requirements.txt

Configure your private .env file with DISCORD_TOKEN.

Run:

    python bot.py

## Security

Never upload your Discord bot token to GitHub.
GitHub Pages only hosts the website. The bot runs separately.
